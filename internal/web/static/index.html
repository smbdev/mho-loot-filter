Glow by rarity

Switch off the coloured glow of each rarity.

Regular gear, insignias, relics and team-up gear glow in the colour of their rarity when they drop. Turn a colour off to remove that glow from every one of those items with that rarity. The items themselves stay visible.

Rarity is decided when an item drops, so it can only switch the glow off, not hide items. Uniques, artifacts, Fortune Cards and chests have their own glow instead; switch that off from Item search.

Backups and restore

Put the game back exactly as it was.

Before a game file is changed for the first time, the original is copied to %LOCALAPPDATA%\MHOLootFilter.

Restoring puts every changed game file back to its original and clears your filter.

After Steam "Verify integrity of game files" or a game update, click Apply to game again.
